ინსტალაცია

  1. ძველი ATAK/DHGM წაშალე (თუ გაქვს).
  2. ჩამოტვირთე და დააინსტალირე DHGM app (Play Protect → „Install anyway").
  3. დააინსტალირე DHGM Drones plugin → Plugin Management-ში ჩართე „დრონები".
  4. დრონისთვის Mac/PC-ზე გაუშვი bridge:
    python3 bridge/dhgm_bridge.py --sim --sim-drones 3 --plugin-tcp 0.0.0.0:14550
⚠️ APK-ები self-signed key-ითაა — Play Store-ის გარეთ. სრული ინსტრუქცია: docs/usage.md
